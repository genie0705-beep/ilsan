# 일산상조 의전계약서 — 설치 안내

## 파일
| 파일 | 역할 |
|---|---|
| `funeral-service-form.html` | 계약서 (실무자 태블릿용) |
| `admin.html` | 관리자 조회 화면 |
| `firestore.rules` | 보안 규칙 (콘솔 Firestore → 규칙 탭에 붙여넣기) |
| `firebase.json` | 배포 설정 |

Firebase 프로젝트 `ilsan-3ec79` 설정값은 이미 들어가 있습니다. 코드 수정은 필요 없습니다.

---

## 1. 콘솔 설정 (5분)

**Authentication** → 시작하기 → 로그인 방법
- **익명** 사용 설정 (실무자 태블릿용, 화면에 나타나지 않음)
- **이메일/비밀번호** 사용 설정 (관리자용)

**Users 탭 → 사용자 추가** — 관리자 계정 생성 (이메일 + 비밀번호).
이 계정으로 `admin.html` 에 로그인합니다. UID 입력은 필요 없습니다.

**Firestore Database** → 데이터베이스 만들기 → 프로덕션 모드 → 위치 `asia-northeast3` (서울)

> 위치는 나중에 변경할 수 없습니다. 반드시 서울로 지정하세요.

---

## 2. 배포 (3줄)

이 폴더에서 실행합니다.

```bash
npm install -g firebase-tools    # 최초 1회만
firebase login
firebase use ilsan-3ec79
firebase deploy
```

---

| 대상 | 주소 |
|---|---|
| 실무자 | `https://ilsan-3ec79.web.app` |

## 4. 실무자 안내 문구 (그대로 전달)

> 아래 링크를 태블릿 크롬(또는 사파리)으로 열어주세요.
> 공유 → 홈 화면에 추가 하시면 앱처럼 바로 열립니다.
>
> https://ilsan-3ec79.web.app
>
> 처음 한 번 '담당자' 버튼을 눌러 본인 이름을 입력해 주세요.
> 작성 후 '저장하기'를 누르면 태블릿에 PDF가 저장되고 본사로 자동 전송됩니다.
> 유가족께는 '고객 전달'을 눌러 카카오톡으로 보내시면 됩니다.

---

## 보안 요약
- 태블릿은 **작성만** 가능하고 저장된 계약서를 조회할 수 없습니다.
- 조회·다운로드는 이메일 계정으로 로그인한 관리자만 가능합니다.
- 인터넷이 끊겨도 작성되며, 통신이 복구되면 자동 전송됩니다.

## 참고
- 개인정보(성명·주소·연락처·서명)가 저장되므로 보관기간과 파기 기준을 정해두시기 바랍니다.
- Storage는 사용하지 않습니다. 서버에는 계약 내용(텍스트)과 서명 이미지만 저장되며 무료(Spark) 요금제로 운영됩니다.
- PDF는 실무자 태블릿에만 저장되어 유가족 전달용으로 쓰입니다.
