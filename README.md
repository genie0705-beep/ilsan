## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 계약서 — 실무자 태블릿용 |
| `admin.html` | 관리자 조회 화면 |
| `firestore.rules` | 보안 규칙 — Firebase 콘솔 Firestore → 규칙 탭에 붙여넣고 게시 |
| `firebase.json` | Firebase Hosting으로 옮길 때만 사용 |

## 저장 구조
- **실무자 태블릿**: '저장하기' → PDF가 태블릿에 저장됨. '고객 전달' → 카카오톡 등으로 유가족께 전송.
- **본사 서버(Firestore)**: 계약 내용(텍스트) + 서명 이미지만 저장. PDF는 올리지 않음.
- 통신이 끊겨도 작성·저장 가능. 통신이 복구되면 자동 전송.
- Storage 미사용, 무료(Spark) 요금제로 운영.

## 업데이트 방법
GitHub 저장소 `ilsan` → Add file → Upload files → 바뀐 파일을 같은 이름으로 올리고 Commit.
1~2분 뒤 반영됩니다. 태블릿에서는 새로고침 한 번.

## 보안 요약
- 태블릿은 작성만 가능, 저장된 계약서 조회 불가.
- 조회·삭제는 이메일 계정으로 로그인한 관리자만 가능.
- 규칙에서 필수 항목(고인·상주 성명, 서명 2개) 없는 데이터는 거부.
